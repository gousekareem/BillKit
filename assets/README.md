# Assets

| Folder | Contents |
|---|---|
| `branding/` | Original BillKit logo (stacked, horizontal light/dark), icon mark, maskable icon, 1024-px app icon, social preview 1200×630 (SVG + PNG) |
| `screenshots/` | Screenshots captured by the Playwright suite (`E2E_SCREENSHOTS=1 npm run test:e2e`) from the running app with **synthetic** sample data |

The web icons (favicon, 192/512 PWA icons, apple-touch icon) are served from `website/public/` (`favicon.svg`, `icons/`, `brand/`). All of them are generated by `website/scripts/generate-brand.mjs` from the same vector mark, so the logo and icons are not stored twice here.
