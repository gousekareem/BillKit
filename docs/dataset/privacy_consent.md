# Consent for real bill images

Real bills can contain names, phone numbers, addresses, partial card numbers, UPI IDs, GSTINs, loyalty numbers and purchase histories. This page describes the process this project expects. It is **not legal advice**, and it does not claim compliance with any law.

1. **Ask first, in writing.** Explain what the image will be used for (development and evaluation of BillKit), who can see it, where it is stored, how long it is kept, and that consent can be withdrawn.
2. **Scope.** Record whether the image may be (a) used internally only, (b) shown in a demo, or (c) redistributed. The default is (a). Do not include images in the ZIP or a public repository unless the owner explicitly authorised (c).
3. **Record.** Fill in `dataset/templates/consent_record_template.csv` (reference number, date, scope). Keep the signed form outside the repository.
4. **Withdrawal.** On request, delete the image, its annotations and every derived file (see `privacy_deletion_retention.md`) and record the withdrawal.
5. **Your own bills** need no consent, but still redact other people's data (for example a co-diner's name on a split bill).
