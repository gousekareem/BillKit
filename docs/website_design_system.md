# Website design system

Source: `website/src/styles/tokens.css` (tokens), `base.css` (elements), `layout.css` (components and layouts).

- **Brand.** Deep teal (`#0f766e` primary, `#115e59` hover) with an amber accent (`#f59e0b`) on ink (`#0b1f2a`). The logo mark is a receipt with a folded corner and a check mark (`assets/branding/`). It is original artwork generated by `website/scripts/generate-brand.mjs`.
- **Colour roles.** Semantic tokens (`--color-bg`, `surface`, `text`, `text-muted`, `primary`, `focus`, …) with light and dark values (`[data-theme='dark']`, following the system setting by default). Status pairs: high confidence (green), needs review (amber), missing (slate), warning (orange), error (red), user-corrected (violet), info (blue). The text/background pairs were chosen for ≥ 4.5:1 contrast. Status is **never** shown by colour alone: every badge has an icon and a text label.
- **Typography.** Inter Variable (self-hosted via @fontsource), with a system fallback stack. Scale 12/14/16/18/20/24/30/36/48 px. Tabular numerals for money.
- **Spacing and shape.** 4-px base spacing scale, radii 6/10/16 px, three shadow levels.
- **Components.** Buttons (primary, secondary, ghost, danger; loading state), form fields with hint/error text, cards, badges (`ReviewBadge`), dialogs (focus-trapped, Esc closes), toasts, empty states, skeletons, progress steps, charts (accessible SVG with text tables), image viewer with evidence-box overlay, page tray.
- **Icons.** lucide-react (ISC licence), used decoratively with `aria-hidden` next to text labels.
- **Layout.** Mobile-first. The app uses bottom navigation under 900 px and a sidebar above it. Content is max 1200 px wide.
- **Motion.** Short transitions only; `prefers-reduced-motion` disables them.
